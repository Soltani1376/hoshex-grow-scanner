# همراه رشد هوشکس — نسخه ۴

این پروژه از یک «ارزیاب رشد» ساده به یک همراه اجرایی روزبه‌روز تبدیل شده است. هدف اصلی این نسخه این است که کاربر فقط توصیه نگیرد؛ یک کار مشخص، خروجی آماده اجرا، ثبت نتیجه و قدم بعدی مبتنی بر همان نتیجه داشته باشد.

## امکانات اصلی
- انتخاب هدف: اینستاگرام، فروش، جذب مشتری، محتوا، مشتری‌های قبلی یا تشخیص توسط هوشکس
- شناخت عمیق‌تر کسب‌وکار: محصول/خدمت، مخاطب، مرحله، کانال فروش، زمان، بودجه و هدف ۳۰ روزه
- مسیر اختصاصی اینستاگرام با داده‌های یک بازه ۳۰ روزه
- سؤال‌های شاخه‌ای برای فروش، جذب مشتری، محتوا و نگهداشت مشتری
- تشخیص همراه با درجه اطمینان و توضیح «چرا این کار؟»
- یک کار اصلی برای امروز به همراه متن، سناریو یا پیام آماده
- امکان گرفتن نسخه جایگزین بدون شلوغ کردن صفحه
- کار دوم اختیاری برای زمانی که کاربر وقت بیشتری دارد
- سه حالت اجرای کار: انجام شد، نیمه‌کاره، نتوانستم انجام بدهم
- ساخت نسخه ساده‌تر در صورت گیر اجرا
- دریافت عددهای واقعی پس از اجرا و ساخت قدم بعدی بر اساس آن‌ها
- دفتر مسیر روزبه‌روز داخل مرورگر
- امکان اصلاح تشخیص توسط خود کاربر
- انتقال خلاصه پرونده به فرم بررسی هوشکس
- ذخیره اطلاعات روی همان دستگاه با LocalStorage
- رابط فارسی، RTL، موبایل‌محور، مینیمال و نئونی

## ساختار
- `index.html` — رابط اصلی نسخه ۴
- `style.css` — طراحی و واکنش‌گرایی
- `app.js` — بارگذار فایل‌های برنامه
- `v4-core.js` — وضعیت، سؤال‌های شاخه‌ای و منطق تشخیص
- `v4-tasks.js` — ساخت کارهای اجرایی و متن‌های آماده
- `v4-ui.js` — تعامل رابط، ثبت نتیجه، دفتر مسیر و ساخت قدم بعدی
- `.github/workflows/validate.yml` — بررسی خودکار نحو جاوااسکریپت و اتصال شناسه‌های رابط

## اجرا
فقط پروژه را با یک وب‌سرور ساده اجرا کنید:

```bash
python3 -m http.server 8080
```

سپس آدرس زیر را باز کنید:

```text
http://localhost:8080
```

## محدودیت فعلی
نسخه فعلی بدون بک‌اند و بدون اتصال مستقیم به مدل هوش مصنوعی اجرا می‌شود. بنابراین نام کاربری اینستاگرام فقط در پرونده ذخیره می‌شود و برنامه هنوز خودکار وارد پیج یا تصاویر آن نمی‌شود. خروجی‌ها توسط منطق شاخه‌ای و بانک اجرایی داخل خود برنامه ساخته می‌شوند.

## مسیر بعدی منطقی
- تحلیل واقعی اسکرین‌شات یا داده پیج با هوش مصنوعی
- ذخیره پرونده روی سرور و ادامه مسیر بین چند دستگاه
- اتصال پرونده به پنل هوشکس
- شخصی‌سازی عمیق‌تر خروجی‌ها با مدل زبانی
- یادگیری از تاریخچه چند هفته‌ای هر کسب‌وکار
