# Hoshex Grow Scanner — V1

نسخه اولیه وب‌اپ اسکن رشد کسب‌وکار برای Hoshex Grow.

## امکانات
- ۱۰ سؤال در ۵ محور: جذب مشتری، آفر، محتوا/برند، فروش/تبدیل، نگهداشت/داده
- Growth Score از ۱۰۰
- تشخیص خودکار ضعیف‌ترین و قوی‌ترین محور
- نسخه رشد ۷ روزه با ۳ اقدام مشخص
- طراحی RTL، موبایل‌فرست، تیره و نئونی
- بدون کتابخانه و بدون بک‌اند؛ مناسب انتشار سریع روی GitHub Pages / Netlify / Vercel
- اشتراک و کپی نتیجه
- ذخیره آخرین نتیجه در LocalStorage

## اجرا
فقط `index.html` را در مرورگر باز کنید. برای اجرای محلی استاندارد:

```bash
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## ساختار
- `index.html` — رابط کاربری
- `style.css` — طراحی و انیمیشن‌ها
- `app.js` — سؤال‌ها، امتیازدهی و تشخیص
- `favicon.svg` — آیکن اولیه
